# 如意

分身软件：打开 App 选一个已安装应用，就能为它生成多个分身。分身是独立安装的普通 App，直接出现在桌面，各自独立数据、独立账号，不用容器、不用进文件夹。

## 原理

提取原应用安装包（含分包）→ ARSCLib 合并分包 → 只改清单里的包名、Provider 标识、自定义权限与任务栈（类名不动）→ 专用密钥重新签名 → 拉起系统安装。改包逻辑与签名校验的边界见应用内说明，Google 登录类强校验应用在分身中可能无法登录，属已知边界。

## 构建

GitHub Actions 自动打包：签名密钥经仓库 Secrets（RUYI_KEYSTORE_B64 / RUYI_KEYSTORE_PASS）注入，ARSCLib 在构建时从其官方 Release 拉取。
